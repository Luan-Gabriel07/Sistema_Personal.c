# Sistema para Personal Trainer

Este projeto consiste em um sistema desenvolvido em linguagem C para auxiliar personal trainers no gerenciamento de alunos e na criação de treinos personalizados.

A ideia surgiu como uma forma de colocar em prática os conhecimentos que estou aprendendo em programação, criando um sistema que tivesse uma aplicação real e que fosse além de simples exercícios de código.

## Sobre o projeto

O sistema funciona através de um menu no terminal, onde o usuário pode cadastrar e consultar alunos, criar treinos e visualizar as informações cadastradas.

Durante o desenvolvimento, foram utilizados diversos conceitos fundamentais da linguagem C, como funções, estruturas condicionais, estruturas de repetição, vetores, matrizes, `struct` e manipulação de strings.

## Funcionalidades

* Sistema de login e cadastro
* Cadastro de alunos
* Listagem dos alunos cadastrados
* Busca de alunos
* Criação de treinos personalizados
* Cadastro de exercícios
* Definição de séries e repetições
* Visualização dos treinos
* Menu de navegação

## Tecnologias utilizadas

* Linguagem C
* Visual Studio Code

### Conceitos utilizados

* Variáveis e tipos de dados
* `if/else` e `switch`
* Estruturas de repetição
* Funções
* Vetores e matrizes
* `struct`
* Manipulação de strings
* Entrada e saída de dados

## Objetivo

O principal objetivo deste projeto foi praticar programação e desenvolver um sistema com uma utilidade prática.

Foi uma oportunidade de transformar os conhecimentos estudados em um projeto completo, trabalhando não apenas a lógica de programação, mas também a organização do código e a criação de funcionalidades que se relacionam entre si.
